# Implementation Plan: Сайт Андрія

**Дата**: 2026-10-02 | **Spec**: [spec.md](spec.md)
**Статус**: попередній технічний план; дослідження бізнес-джерел ще не виконано.

## Summary

Спочатку збираємо перевірені факти й реальні фото, потім створюємо структуру та сайт. Обсяг секцій залежить від доказів. Робота йде послідовно з перевіркою кожного етапу.

## Technical Context

Обраний простий початковий підхід: статичні HTML, CSS і мінімальний JavaScript без серверної частини та обов'язкових npm-залежностей. Для односторінкового сайту це дає просте розміщення та мало коду. Якщо дослідження виявить потребу в іншій архітектурі, оновити план перед реалізацією.

- Зберігання: локальні фото й документований реєстр джерел.
- Ціль: мобільні та настільні браузери.
- Перевірка: браузерний огляд, клавіатура, контроль посилань і джерел; доступні інструменти визначити перед реалізацією.
- Швидкість: адаптивні розміри фото, зазначені width/height, відкладене завантаження поза першим екраном; зафіксувати фактичні вимірювання, якщо інструменти доступні.
- Форми та бекенд: відсутні, доки немає підтвердженої потреби й доставки звернень.

## Constitution Check

Перед версткою перевірити: кожне твердження має доказ; фото власні; приватні матеріали виключені; немає вигаданих контактів. Перед завершенням повторити ці перевірки та перевірити доступність.

## Етапи й вихідні результати

1. **Дослідження** → `docs/sources.md`: доступність профілів, реєстр фактів і фотографій, непідтверджені дані. Не заповнювати реєстр припущеннями.
2. **Контент і дизайн** → `docs/content-map.md`: секції, тексти з посиланнями на записи джерел, палітра й композиція. Перевірити орієнтири Geberit, TECE, Villeroy & Boch.
3. **US1** → перший екран, послуги та контакт; перевірка користувацького шляху.
4. **US2** → реальні роботи та підтверджені матеріали; перевірка відповідності джерелам.
5. **US3** → про майстра та наданий відгук; перевірка змісту.
6. **Завершення** → адаптивність, доступність, SEO, оптимізація, `README.md` і `docs/delivery-report.md`.

## Запуск після реалізації

Планована команда з кореня: `python3 -m http.server 8000`; відкрити `http://localhost:8000`. Збірка для звичайного статичного сайту не потрібна. Перевірити наявність Python перед використанням і виконати цю команду під час фінальної перевірки.
