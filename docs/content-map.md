## Палітра (FR-005)

**Оновлено 2026-10-02:** палітру перебудовано навколо фірмового логотипа `lys_montage.png`. Кольори взяті піпеткою з самого файлу, тому сайт і логотип звучать в унісон. Композиційні принципи орієнтирів (Geberit / TECE / Villeroy & Boch) збережено: чисті світлі поверхні, точна геометрія, багато повітря — змінився лише акцентний колір із синього на фірмовий помаранчевий.

| Токен | Колір | Використання |
|---|---|---|
| `--c-fox` | `#f05e1b` | Фірмовий помаранчевий із логотипа: кнопки, акценти, графіка |
| `--c-fox-ink` | `#bf4408` | Затемнений помаранчевий для текстових посилань (AA на білому) |
| `--c-fox-deep` | `#d9500f` | Hover для помаранчевих поверхонь |
| `--c-ink` | `#292d30` | Графіт із логотипа: темні секції, заголовки, футер |
| `--c-ink-900` | `#1b1e20` | Текст на помаранчевих поверхнях |
| `--c-white` | `#ffffff` | Основний фон |
| `--c-fog` | `#f8f6f4` | Тепло-білий вторинний фон (підтон під помаранчевий) |
| `--c-graphite` | `#33383d` | Основний текст |
| `--c-grey` | `#6c7279` | Другорядний текст |
| `--c-border` | `#e8e3de` | Теплі межі, роздільники |

Легасі-токени `--c-navy`, `--c-blue`, `--c-red` збережені як аліаси на нові кольори, щоб не переписувати всі правила.

### Контраст (виміряно, WCAG 2.1)

| Пара | Коефіцієнт | Висновок |
|---|---|---|
| Текст `#33383d` на білому | 11.84 | AAA |
| Другорядний `#6c7279` на білому | 4.86 | AA |
| Посилання `#bf4408` на білому | 5.19 | AA |
| Текст кнопки `#1b1e20` на помаранчевому | 5.04 | AA |
| Білий на графіті | 13.89 | AAA |
| Текст кроків `#c9cdd1` на графіті | 8.69 | AAA |
| Номери `#f8824a` на графіті | 5.48 | AA |
| Чистий `#f05e1b` на білому | 3.32 | лише графіка й великий текст (≥3:1), не для дрібного тексту |

Через останній рядок прийнято два рішення: **кнопки — помаранчеві з темним текстом** (а не білим, бо білий на помаранчевому дає лише 3.3:1), а **текстові посилання — затемненим `--c-fox-ink`**. Так фірмовий колір лишається точним там, де він великий, і темнішає там, де це дрібний текст.

Фокус-кільце — графітове (`--c-ink`), бо помаранчеве було б невидимим на помаранчевих кнопках.

## Логотип і фавікон

- Джерело: `lys_montage.png` (наданий замовником 2026-10-02).
- `assets/images/logo-lys.png` — обрізаний логотип із прозорим фоном, у шапці.
- `assets/images/logo-lys-light.png` — те саме, але графітовий вордмарк перефарбовано в білий, для темного футера.
- `assets/images/favicon-512.png`, `favicon-32.png`, `apple-touch-icon.png` — голова лиса, вирізана з логотипа, по центру квадрата з полями, прозорий фон.
- `<meta name="theme-color" content="#f05e1b">` — колір адресного рядка на мобільних.

Типографіка: системний шрифтовий стек (`-apple-system, Segoe UI, Roboto, sans-serif`) — без зовнішніх залежностей, для гарантованого офлайн-рендеру та швидкості. Заголовки — трохи щільніший трекінг, велика вага; текст — комфортний line-height (1.6).

## Секції, які пропускаються

- Форма заявки — не додається (немає підтвердженої доставки повідомлень); використовується пряме посилання на Instagram і телефон.
- Сертифікати/гарантії як розділ — пропущено (непідтверджено).
- Ціни — не публікуються (рішення команди, див. sources.md).
- Контент підбірки historie «Об'єкти» та автомобільні підбірки особистого профілю — не використовуються (нерелевантно/недоступно).
